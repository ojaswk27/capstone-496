# Rocket Propulsion and Design
## Reference Document for Aerospace Design Assistant

### 1. Fundamental Rocket Equations

#### 1.1 Tsiolkovsky Rocket Equation

The ideal rocket equation (Tsiolkovsky equation):
Δv = v_e * ln(m_0 / m_f) = I_sp * g_0 * ln(m_0 / m_f)

Where:
- Δv = Change in velocity (m/s)
- v_e = Effective exhaust velocity (m/s)
- I_sp = Specific impulse (seconds)
- g_0 = Standard gravity (9.80665 m/s²)
- m_0 = Initial mass (kg)
- m_f = Final mass (kg)

Mass ratio:
MR = m_0 / m_f = exp(Δv / v_e)

#### 1.2 Thrust Equation

Rocket thrust:
F = ṁ * v_e + (p_e - p_a) * A_e

Where:
- ṁ = Mass flow rate (kg/s)
- v_e = Exhaust velocity (m/s)
- p_e = Exit pressure (Pa)
- p_a = Ambient pressure (Pa)
- A_e = Nozzle exit area (m²)

At optimal expansion (p_e = p_a):
F = ṁ * v_e

#### 1.3 Specific Impulse

Specific impulse:
I_sp = F / (ṁ * g_0) = v_e / g_0

Typical values:
- Solid propellant: 200-280 s
- Liquid bipropellant: 300-450 s
- Liquid hydrogen/oxygen: 420-460 s
- Ion propulsion: 1,500-10,000 s

Higher I_sp = more efficient = less propellant needed.

### 2. Propellant Performance

#### 2.1 Characteristic Velocity

Characteristic velocity (c*):
c* = p_c * A_t / ṁ

Where:
- p_c = Chamber pressure (Pa)
- A_t = Throat area (m²)

Theoretical c*:
c* = √(γ * R * T_c / M) / Γ

Where Γ is a function of γ:
Γ = √(γ * (2/(γ+1))^((γ+1)/(γ-1)))

#### 2.2 Thrust Coefficient

Thrust coefficient:
C_F = F / (p_c * A_t)

For ideal expansion:
C_F = Γ * √(2*γ²/(γ-1) * (2/(γ+1))^((γ+1)/(γ-1)) * (1 - (p_e/p_c)^((γ-1)/γ)))

Typical values: C_F = 1.4-1.9

Specific impulse relationship:
I_sp = (c* * C_F) / g_0

#### 2.3 Common Propellant Combinations

Solid Propellants:
- APCP (Ammonium Perchlorate Composite): I_sp ≈ 260-280 s
- Black powder: I_sp ≈ 80-100 s (model rockets)

Liquid Bipropellants:
- LOX/RP-1: I_sp ≈ 300-350 s
- LOX/LH2: I_sp ≈ 420-460 s
- N2O4/UDMH: I_sp ≈ 290-320 s
- LOX/Methane: I_sp ≈ 350-380 s

Hybrid:
- N2O/HTPB: I_sp ≈ 230-280 s

### 3. Nozzle Design

#### 3.1 Nozzle Geometry

Throat area:
A_t = ṁ * √(R * T_c / (γ * M)) / (p_c * Γ)

Area ratio (expansion ratio):
ε = A_e / A_t

Optimal expansion ratio depends on:
- Operating altitude
- Chamber pressure
- Propellant properties

#### 3.2 Expansion Ratio Selection

For optimal expansion (p_e = p_a):
ε = (1/M_e) * ((2/(γ+1)) * (1 + ((γ-1)/2)*M_e²))^((γ+1)/(2*(γ-1)))

Where M_e is the exit Mach number.

At sea level: ε ≈ 10-15
At vacuum: ε ≈ 50-200

#### 3.3 Nozzle Types

Conical nozzle:
- Half-angle: 15-20°
- Length: L = (r_e - r_t) / tan(α)
- Divergence loss: λ = (1 + cos(α)) / 2

Bell nozzle:
- Shorter length for same expansion
- Better performance (λ ≈ 0.98-0.99)

### 4. Rocket Performance

#### 4.1 Thrust-to-Weight Ratio

Thrust-to-weight ratio:
TWR = F / (m * g_0)

Requirements:
- Vertical launch: TWR > 1.0
- Typical at liftoff: TWR = 1.2-1.5
- Upper stages: TWR = 0.5-1.0 acceptable

#### 4.2 Burn Time

Burn time:
t_b = m_p / ṁ

Where m_p is propellant mass.

For solid rockets:
t_b = ρ_p * V_p / ṁ

Average acceleration:
a_avg = (Δv / t_b) + g_0 (for vertical launch)

#### 4.3 Structural Mass Fraction

Structural coefficient:
ε_s = m_s / (m_s + m_p)

Where m_s is structural mass (everything except propellant).

Payload ratio:
λ = m_payload / m_0

Typical structural coefficients:
- Solid rockets: ε_s = 0.08-0.15
- Liquid rockets: ε_s = 0.05-0.12

### 5. Staging

#### 5.1 Staging Benefits

Single-stage Δv is limited by:
Δv_max = v_e * ln(1/ε_s)

For ε_s = 0.1, v_e = 3000 m/s:
Δv_max = 3000 * ln(10) = 6,900 m/s

Not enough for orbit (~9,400 m/s with losses).

#### 5.2 Optimal Staging

For n identical stages:
Δv_total = n * v_e * ln(MR_stage)

Optimal mass ratio per stage:
MR_opt = (m_0/m_f)^(1/n)

#### 5.3 Two-Stage Optimization

For minimum initial mass:
MR_1 * MR_2 = MR_total

Optimal split (equal I_sp):
MR_1 = MR_2 = √(MR_total)

With different I_sp:
Δv_1 / v_e1 = Δv_2 / v_e2

### 6. Trajectory and Orbit Insertion

#### 6.1 Gravity Losses

Gravity loss:
Δv_gravity = g * t_b * sin(θ_avg)

For vertical launch:
Δv_gravity ≈ g * t_b (worst case)

Typical gravity losses: 1,000-1,500 m/s to orbit.

#### 6.2 Drag Losses

Drag loss:
Δv_drag = ∫(D/m) dt

Typical drag losses: 50-200 m/s to orbit.

Minimized by:
- Higher thrust (shorter time in atmosphere)
- Streamlined vehicle
- Optimal trajectory

#### 6.3 Orbital Velocity Requirements

Low Earth Orbit (400 km):
v_orbit = √(μ / r) = √(3.986e14 / 6.771e6) = 7,672 m/s

Total Δv to LEO:
Δv_total = v_orbit + Δv_gravity + Δv_drag + Δv_steering
Δv_total ≈ 9,200-9,500 m/s

### 7. Model Rocket Specific

#### 7.1 Motor Classifications

Total impulse classes:
- A: 1.26-2.5 N·s
- B: 2.51-5.0 N·s
- C: 5.01-10.0 N·s
- D: 10.01-20.0 N·s
- E: 20.01-40.0 N·s
- F: 40.01-80.0 N·s
- G: 80.01-160.0 N·s
- H: 160.01-320.0 N·s (High Power)

Each letter doubles the total impulse.

#### 7.2 Altitude Prediction

Simplified altitude (no drag):
h = (I_total / (m_avg * g))² / (2 * g)

With drag (approximate):
h ≈ h_burnout + v_burnout² / (2*g) * (1 - k*v_burnout)

Where k accounts for drag.

#### 7.3 Stability

Stability margin:
SM = (CP - CG) / d

Where d is body diameter.

Recommended stability:
- SM = 1.0-2.0 calibers (body diameters)
- Too stable (SM > 3): weathercocks
- Unstable (SM < 0): tumbles

### 8. Example Rockets

#### 8.1 Model Rocket (Estes Alpha)
- Total impulse: 5 N·s (C6-5)
- Burn time: 1.7 s
- Average thrust: 3 N
- Dry mass: 28 g
- Propellant mass: 12 g
- Altitude: ~300 m

#### 8.2 High Power Rocket (Level 1)
- Total impulse: 640 N·s (H motor)
- Burn time: 2.5 s
- Average thrust: 256 N
- Dry mass: 2 kg
- Propellant mass: 0.5 kg
- Altitude: ~1,500 m

#### 8.3 Falcon 9 First Stage
- Thrust (SL): 7,607 kN
- I_sp (SL): 282 s
- I_sp (vac): 311 s
- Propellant mass: 395,700 kg
- Dry mass: 22,200 kg
- Burn time: 162 s
