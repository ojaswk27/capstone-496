# Aircraft Propulsion Systems
## Reference Document for Aerospace Design Assistant

### 1. Propeller Theory

#### 1.1 Momentum Theory

Ideal thrust from momentum theory:
T = ṁ * (V_e - V_0) = ρ * A * V_avg * (V_e - V_0)

Where:
- ṁ = Mass flow rate (kg/s)
- V_0 = Freestream velocity (m/s)
- V_e = Exit velocity (m/s)
- A = Propeller disk area (m²)

Ideal efficiency (Froude efficiency):
η_ideal = 2 / (1 + V_e/V_0) = 2 / (1 + √(1 + T/(0.5*ρ*A*V_0²)))

#### 1.2 Blade Element Theory

Local blade element forces:
dL = 0.5 * ρ * W² * c * C_l * dr
dD = 0.5 * ρ * W² * c * C_d * dr

Where:
- W = Resultant velocity at blade element
- c = Local chord
- r = Radial position

Resultant velocity:
W = √((Ω*r)² + V_0²)

Inflow angle:
φ = arctan(V_0 / (Ω*r))

#### 1.3 Propeller Coefficients

Thrust coefficient:
C_T = T / (ρ * n² * D⁴)

Power coefficient:
C_P = P / (ρ * n³ * D⁵)

Advance ratio:
J = V / (n * D)

Propeller efficiency:
η = J * C_T / C_P = T * V / P

Where n is rotational speed (rev/s) and D is diameter (m).

#### 1.4 Static Thrust

At static conditions (V = 0):
T_static = C_T0 * ρ * n² * D⁴

Approximate static thrust:
T_static ≈ 0.5 * ρ * A * (P * η_static / A)^(2/3)

Static thrust coefficient C_T0 typically 0.05-0.10.

### 2. Piston Engine Performance

#### 2.1 Power Output

Brake horsepower:
BHP = (BMEP * V_d * N) / (2 * 60) for 4-stroke

Where:
- BMEP = Brake mean effective pressure (Pa)
- V_d = Displacement volume (m³)
- N = RPM

Power variation with altitude (normally aspirated):
P_alt / P_SL = (ρ_alt / ρ_SL)^0.765

Power variation with altitude (turbocharged):
P_alt / P_SL = 1.0 up to critical altitude

#### 2.2 Specific Fuel Consumption

Brake specific fuel consumption:
BSFC = Fuel_flow_rate / Power (kg/W/s or lb/hp/hr)

Typical values:
- Gasoline piston: 0.4-0.5 lb/hp/hr
- Diesel piston: 0.35-0.45 lb/hp/hr
- Turboprop: 0.5-0.6 lb/shp/hr

Fuel flow rate:
ṁ_fuel = BSFC * P

#### 2.3 Engine Sizing

Required engine power:
P_required = (D * V) / η_prop

At cruise:
P_cruise = (0.5 * ρ * V³ * S * C_D) / η_prop

For climb capability:
P_available > P_required + W * ROC

### 3. Electric Propulsion

#### 3.1 Motor Characteristics

Motor power:
P_motor = τ * ω = V * I * η_motor

Torque-speed relationship:
τ = K_t * (I - I_0)
ω = (V - I * R_m) / K_e

Where:
- K_t = Torque constant (Nm/A)
- K_e = Back-EMF constant (V/rad/s)
- R_m = Motor resistance (Ω)
- I_0 = No-load current (A)

For brushless motors: K_t ≈ K_e = 1 / (KV * 2π/60)

#### 3.2 Motor Efficiency

Motor efficiency:
η_motor = P_mech / P_elec = (τ * ω) / (V * I)

Losses:
P_loss = I² * R_m + P_iron + P_friction

Peak efficiency typically at 70-85% of max power.

#### 3.3 ESC and Power Electronics

ESC efficiency: 95-98% at optimal load
Total propulsion efficiency:
η_total = η_motor * η_ESC * η_prop

### 4. Turboprop Engines

#### 4.1 Performance Characteristics

Equivalent shaft horsepower:
ESHP = SHP + (T_jet * V) / 550

Where T_jet is residual jet thrust.

Thrust:
T = (η_prop * ESHP * 550) / V + T_jet

Specific fuel consumption:
ESFC = ṁ_fuel / ESHP

#### 4.2 Altitude Effects

Turboprop power lapse:
P_alt / P_SL = (ρ_alt / ρ_SL)^0.7

For turbofans:
T_alt / T_SL = (ρ_alt / ρ_SL)^1.0

### 5. Propeller Selection

#### 5.1 Fixed-Pitch Propeller Sizing

Design for cruise efficiency:
J_design = V_cruise / (n_cruise * D)

Select pitch for J_design in efficient range (η > 0.8).

Static thrust considerations:
- Lower pitch = better static thrust
- Higher pitch = better cruise efficiency

#### 5.2 Variable-Pitch Propeller

Constant-speed operation:
- Governor maintains n = constant
- Pitch adjusts for varying V and P

Blade angle range typically 15-45°.

#### 5.3 Propeller Diameter Selection

Maximum diameter limited by:
- Ground clearance
- Tip Mach number (M_tip < 0.85)

Tip Mach number:
M_tip = √((π*n*D)² + V²) / a

Where a = speed of sound.

Larger diameter preferred for efficiency:
η ∝ √(D) at fixed power and speed

### 6. Propulsion System Matching

#### 6.1 Matching Engine and Propeller

Power absorbed by propeller:
P = C_P * ρ * n³ * D⁵

Engine power available:
P_engine = f(n, throttle)

Match point: P_engine = P_prop at desired n.

#### 6.2 Gear Reduction

Gear ratio:
GR = n_engine / n_prop

Reasons for reduction:
- Optimize propeller RPM for efficiency
- Reduce tip speeds
- Increase torque

Common ratios: 2:1 to 3:1

### 7. Example Systems

#### 7.1 Cessna 172 (Lycoming IO-360)
- Engine: 180 hp (134 kW)
- Propeller: 76" (1.93 m) diameter
- Fixed pitch
- Cruise RPM: 2400
- BSFC: 0.42 lb/hp/hr
- J at cruise: 0.7
- η_prop at cruise: 0.82

#### 7.2 Electric UAV (5 kg MTOW)
- Motor: 500W brushless, 700KV
- Propeller: 12x6"
- ESC: 40A
- Battery: 4S 5000mAh
- Static thrust: 2.2 kg
- Cruise efficiency: 75%
- Endurance: 45 min
