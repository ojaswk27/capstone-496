- Fixed gear: CD = 0.25-0.35 (per strut)
- Wheel fairing: CD = 0.15-0.25
- Retracted: CD = 0.01-0.02

Antennas:
- Wire antenna: CD = 1.0-1.2
- Blade antenna: CD = 0.5-0.8
- Conformal: CD ≈ 0

External stores:
- Fuel tank: CD = 0.15-0.30
- Bomb shape: CD = 0.20-0.35
- Missile: CD = 0.15-0.25

#### 2.2 3D Wing CL_max

CL_max depends on aspect ratio:
CL_max_3D ≈ CL_max_2D × 0.9 (for AR=6)
CL_max_3D ≈ CL_max_2D × 0.95 (for AR=12)

With high-lift devices:
| Configuration | CL_max |
|---------------|--------|
| Clean wing | 1.3-1.6 |
| Plain flaps | 1.8-2.2 |
| Slotted flaps | 2.2-2.8 |
| Fowler flaps | 2.5-3.2 |
| Slats + flaps | 3.0-3.8 |

#### 2.3 Lift Curve Slope

2D airfoil theory: a_0 = 2π per radian = 0.11 per degree

3D finite wing:
a = a_0 / (1 + a_0/(π × e × AR))

Example values:
| AR | a (per degree) |
|----|----------------|
| 4 | 0.068 |
| 6 | 0.078 |
| 8 | 0.085 |
| 10 | 0.089 |
| 20 | 0.099 |
| ∞ | 0.110 |

### 4. Parasitic Drag Breakdown

#### 4.1 Skin Friction

Laminar flat plate:
Cf = 1.328 / √Re

Turbulent flat plate:
Cf = 0.074 / Re^0.2 (approximate)
Cf = 0.455 / (log10(Re))^2.58 (Schlichting)

Transition Reynolds number:
Re_tr ≈ 500,000 (smooth surface)
Re_tr ≈ 100,000 (rough surface)

#### 4.2 Form Factor

Fuselage form factor:
FF = 1 + 60/(L/D)³ + 0.0025×(L/D)

Wing form factor:
FF = 1 + 0.6×(t/c)/(x/c) + 100×(t/c)⁴

Where x/c is position of max thickness.

Typical form factors:
- Streamlined fuselage: FF = 1.1-1.2
- Wing (12% thick): FF = 1.2-1.3
- Nacelle: FF = 1.3-1.5

#### 4.3 Interference Drag

Wing-fuselage: Add 5-10% to sum
Nacelle-wing: Add 10-20%
Landing gear: Add 5-10%

Total interference:
ΔCD_int ≈ 0.05-0.10 × CD_0_components

### 5. Complete Aircraft Drag

#### 5.1 Drag Buildup Method

CD_0 = Σ(Cf × FF × Q × S_wet,i) / S_ref

Where:
- Cf = Skin friction coefficient
- FF = Form factor
- Q = Interference factor
- S_wet = Wetted area

#### 5.2 Typical CD_0 Values

| Aircraft Type | CD_0 |
|---------------|------|
| Clean sailplane | 0.010-0.015 |
| GA single (retract) | 0.020-0.025 |
| GA single (fixed) | 0.025-0.035 |
| Light twin | 0.025-0.030 |
| Business jet | 0.018-0.022 |
| Transport | 0.015-0.020 |
| Fighter | 0.015-0.025 |
| WWI biplane | 0.050-0.070 |

#### 5.3 Drag Polar

Parabolic drag polar:
CD = CD_0 + k × CL²

Where k = 1/(π × e × AR)

Oswald efficiency:
e = 0.75-0.85 (typical)
e = 0.7-0.8 (low aspect ratio)
e = 0.85-0.95 (sailplane)

### 6. Reynolds Number Effects

#### 6.1 CD Variation with Re

Sphere:
- Re < 10⁵: CD ≈ 0.4
- Re = 2×10⁵: CD drops to 0.1 (critical)
- Re > 10⁶: CD ≈ 0.2

Cylinder (normal):
- Re < 10⁵: CD ≈ 1.2
- Re > 10⁶: CD ≈ 0.3

#### 6.2 Airfoil Re Effects

Low Re (< 10⁵):
- Laminar separation bubbles
- Higher CD
- Lower CL_max

High Re (> 10⁷):
- Mostly turbulent
- Lower CD (relative to mid-Re)
- Predictable behavior

### 7. Mach Number Effects

#### 7.1 Compressibility Corrections

Prandtl-Glauert (subsonic):
CD = CD_0 / √(1 - M²)

Valid for M < 0.7

#### 7.2 Wave Drag

Above critical Mach:
CD_wave increases rapidly

Lock-Spreiter formula:
CD_wave = 20 × (M - M_crit)⁴

Supercritical airfoils:
Delay M_crit by 0.05-0.10

#### 7.3 Typical Mach Effects

| M | CD/CD_0 (unswept) |
|---|-------------------|
| 0.0 | 1.00 |
| 0.6 | 1.06 |
| 0.7 | 1.10 |
| 0.8 | 1.25 |
| 0.9 | 2.0+ |
| 1.0 | 3.0+ |

### 8. Reference Areas

#### 8.1 Standard References

Wing planform area (S):
- Most common for aircraft
- Includes fuselage carrythrough

Frontal area:
- Bluff bodies
- Automotive
- Some UAVs

Wetted area:
- Friction drag calculations
- Comparison between designs

#### 8.2 Wetted Area Ratios

S_wet/S for aircraft:
- Flying wing: 2.0-2.5
- Conventional: 5-7
- Transport: 6-8
- Fighter: 4-6
