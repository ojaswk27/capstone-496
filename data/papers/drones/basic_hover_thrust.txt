# Basic Hover Thrust Calculations for Rotorcraft
## Fundamental Equations for Aerospace Design Assistant

### 1. Hover Equilibrium - The Most Important Equation

For any aircraft in steady hover (no acceleration), the thrust must exactly equal the weight:

**T = W = mass * g**

Where:
- T = Total thrust required (N)
- W = Weight of the aircraft (N)
- mass = Total aircraft mass including payload (kg)
- g = Gravitational acceleration (m/s²), standard value 9.81 m/s²

This is the **starting point** for all hover calculations. Once you know the required thrust, you can then calculate other parameters like rotor size, power requirements, etc.

Example: A drone with total mass of 5 kg needs thrust:
T = 5 kg × 9.81 m/s² = 49.05 N

### 2. Mass Budget for Drones

Total mass breakdown:
- mass_total = mass_payload + mass_airframe + mass_battery + mass_motors + mass_electronics

Typical mass ratios for photography drones:
- Payload: 20-40% of total mass
- Battery: 25-35% of total mass
- Airframe + motors + electronics: 30-50% of total mass

### 3. Thrust-to-Weight Ratio

For stable hover with control authority, multirotors need excess thrust:

**T_max = TWR × mass × g**

Where TWR (Thrust-to-Weight Ratio) is typically:
- Minimum for hover: TWR = 1.0 (borderline unstable)
- Stable hover: TWR = 1.5 to 2.0
- Agile/Racing drones: TWR = 3.0 to 6.0
- Photography drones: TWR = 1.8 to 2.5

Example: A 5 kg photography drone with TWR = 2.0 needs:
T_max = 2.0 × 5 kg × 9.81 m/s² = 98.1 N total thrust from all rotors

For a quadcopter, each motor/propeller must provide:
T_per_motor = T_max / 4 = 24.5 N

### 4. Relating Thrust to Momentum Theory

Once you know required thrust T, you can calculate the induced velocity using momentum theory:

**v_i = √(T / (2 * ρ * A))**

Where:
- v_i = Induced velocity through the rotor disk (m/s)
- ρ = Air density (kg/m³), typically 1.225 kg/m³ at sea level
- A = Total rotor disk area (m²)

For multiple rotors:
A_total = n_rotors × π × R²

Where R is the radius of each rotor.

### 5. Power Requirements

The ideal power required for hover:

**P_ideal = T × v_i**

Or, substituting the induced velocity:

**P_ideal = T^(3/2) / √(2 * ρ * A)**

Accounting for real-world inefficiencies:

**P_actual = P_ideal / FM**

Where FM (Figure of Merit) is typically 0.6-0.75 for small rotors.

### 6. Complete Design Flow for Hover

Step-by-step calculation procedure:

1. Define payload mass: mass_payload
2. Estimate airframe mass: mass_airframe ≈ 1.5 × mass_payload (rough estimate)
3. Calculate total mass: mass_total = mass_payload + mass_airframe
4. Calculate hover thrust: T_hover = mass_total × g
5. Choose TWR (e.g., 2.0 for photography drone)
6. Calculate max thrust: T_max = TWR × mass_total × g
7. Calculate thrust per rotor: T_per_rotor = T_max / n_rotors
8. Choose rotor diameter based on space constraints
9. Calculate rotor area: A_per_rotor = π × R²
10. Calculate induced velocity: v_i = √(T_hover / (2 * ρ * A_total))
11. Calculate hover power: P_hover = T_hover × v_i / FM
12. Size battery based on required flight time

### 7. Quick Reference Formulas

**Thrust in Hover:**
```
T = mass * g
```

**Maximum Thrust Capability:**
```
T_max = TWR * mass * g
```

**Induced Velocity:**
```
v_i = sqrt(T / (2 * rho * A))
```

**Hover Power:**
```
P_hover = (T^(3/2) / sqrt(2 * rho * A)) / FM
```

**Flight Time Estimate:**
```
t_flight = (battery_capacity * battery_voltage * battery_efficiency) / P_hover
```

### 8. Worked Example: 2kg Payload Photography Drone

Given:
- Payload mass: 2.0 kg
- Desired TWR: 2.0
- Number of rotors: 4 (quadcopter)
- Rotor diameter: 0.25 m (250 mm propellers)

Solution:

Estimate total mass (payload + 1.5× for airframe):
mass_total = 2.0 + 3.0 = 5.0 kg

Hover thrust required:
T_hover = 5.0 × 9.81 = 49.05 N

Maximum thrust needed (with TWR = 2.0):
T_max = 2.0 × 5.0 × 9.81 = 98.1 N

Thrust per motor at max:
T_per_motor = 98.1 / 4 = 24.5 N

Rotor area per rotor:
A = π × (0.125)² = 0.0491 m²

Total rotor area:
A_total = 4 × 0.0491 = 0.196 m²

Induced velocity in hover:
v_i = √(49.05 / (2 × 1.225 × 0.196)) = √(49.05 / 0.48) = √102.2 = 10.1 m/s

Ideal hover power:
P_ideal = 49.05 × 10.1 = 495 W

Actual hover power (FM = 0.7):
P_actual = 495 / 0.7 = 707 W

This example shows the complete calculation chain starting from the fundamental hover equation.
