# Aerospace Design Assistant - Usage Guide

## Prerequisites

- Python 3.10+
- [Ollama](https://ollama.com/) installed and running
- A compatible model pulled (see Model Selection below)

### Install dependencies

```bash
pip install -r requirements.txt
```

### Start Ollama

```bash
ollama serve
```

### Pull a model

```bash
ollama pull qwen2.5:7b      # Recommended: fast, reliable
ollama pull qwen3.5:latest   # Alternative: smarter but slower (9.7B)
```

## Running the Assistant

### Single design request

```bash
python main.py --design "quadcopter drone with 1kg payload and 20 minute flight time"
```

### Interactive mode

```bash
python main.py --interactive
```

Type your design request at the `Design >` prompt. Type `quit` to exit.

### Check configuration

```bash
python main.py --status
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama server URL |
| `OLLAMA_MODEL` | `qwen3.5:latest` | Model to use for inference |

Override per-run:

```bash
OLLAMA_MODEL=qwen2.5:7b python main.py --design "..."
```

## Supported Vehicle Types

The assistant auto-classifies your request into one of six vehicle types, each with specialized calculation tools:

| Vehicle | Example Prompt | Tools |
|---------|---------------|-------|
| **Drone** | "quadcopter with 1kg payload, 20min flight" | `size_drone`, `calculate_hover_thrust`, `calculate_flight_time` |
| **Fixed Wing** | "surveillance aircraft, 5kg payload, 200km range" | `size_aircraft`, `calculate_lift`, `calculate_stall_speed` |
| **Helicopter** | "light helicopter, 400kg payload, 500km range" | `design_helicopter` |
| **Rocket** | "model rocket to 500m altitude, 0.5kg payload" | `design_rocket`, `tsiolkovsky_delta_v` |
| **Satellite** | "earth observation sat, 20kg payload, 600km orbit" | `design_satellite`, `calculate_orbital_velocity`, `calculate_orbital_period` |
| **Glider** | "competition glider, 15m class, cross-country" | `design_glider`, `calculate_glide_performance`, `calculate_best_glide_speed` |

## Model Selection

| Model | Speed | Quality | Best For |
|-------|-------|---------|----------|
| `qwen2.5:7b` | Fast (~20s/request) | Good | Development, quick iterations |
| `qwen3.5:latest` | Slow (~2-5min) | Better | Final designs, complex requests |
| `llama3:latest` | Fast | Moderate | Alternative if Qwen unavailable |

## Architecture

The system uses a LangGraph state machine with four LLM sub-agents:

```
User Input
    |
    v
[Understand Agent] -- classifies vehicle type, extracts requirements
    |
    v
[Parameter Agent]  -- fills missing parameters using engineering reasoning
    |
    v
[Design Agent]     -- calls calculation tools via Ollama function-calling
    |
    v
[Validate Agent]   -- reviews design against requirements
    |                  (retries up to 2x if validation fails)
    v
[Synthesize]       -- formats final output (no LLM, pure code)
```

All routing between agents is deterministic (code-based, not LLM-decided).

## Troubleshooting

**"Server disconnected without sending a response"**
- Ollama isn't running. Start it with `ollama serve`.

**Very slow responses (>2 minutes)**
- Switch to a smaller model: `OLLAMA_MODEL=qwen2.5:7b python main.py --design "..."`

**"No design data to synthesize"**
- The LLM failed to call calculation tools. Try again or use a different model.

**Validation errors in output**
- These are generated by the Validate Agent reviewing the design. Warnings/errors indicate the design may not fully meet requirements but the output is still shown.
